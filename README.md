# Ритм смен — календарь сменного графика

Одностраничное веб-приложение (PWA): календарь рабочих смен на двоих и более человек.
У каждого — своя фотография, цвет и живой статус смены на сегодня. Без сервера и базы
данных: весь график вычисляется по формуле из даты старта и паттерна.

## Что умеет

- **Герой «Сегодня»** — карточки людей с фото, статусом «В смене / Отдыхает»,
  обратным отсчётом до перехода и дорожкой текущего цикла.
- **Фотографии** — загрузка с авто-кропом в квадрат и сжатием; без фото — инициал на
  градиенте цвета человека.
- **Календарь-«партитура»** — в каждом дне работающих показывают их мини-аватары,
  а фон дня мягко светится цветом.
- Двое и больше людей, свои цвета и графики (2/2, 3/3, 1/3, 5/2 или свой).
- Свайп по календарю, плавные переходы месяцев (View Transitions), тёмная/светлая тема.
- Ставится «как приложение» на iPhone/Android, работает офлайн.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Всё приложение (HTML + CSS + JS в одном файле) |
| `manifest.webmanifest` | Манифест PWA (иконка, имя, standalone-режим) |
| `sw.js` | Service worker — офлайн-работа |
| `icon-192.png`, `icon-512.png` | Иконки приложения |

## Как пользоваться

1. **Настройки (⚙ вверху справа):** для каждого человека задать имя, цвет,
   дату любого известного рабочего дня и график (2/2, 3/3, 1/3, свой и т.д.).
   Чтобы у напарника был сдвиг — поставить ему другую дату старта.
2. **Легенда** сверху показывает, кто каким цветом.
3. В ячейке дня — цветные полоски: чей цвет, тот в этот день работает.
4. Стрелки ‹ › листают месяцы, «Сегодня» возвращает к текущему.
5. **◐** — переключение светлой/тёмной темы.

## Синхронизация между устройствами (без сервера)

Настройки хранятся в браузере устройства (`localStorage`). Чтобы одинаковый график
был везде: в настройках нажать **«🔗 Скопировать ссылку с настройками»** — в ссылку
зашиваются все люди и графики. Открыть эту ссылку на других устройствах (или сохранить
в закладки) — там появятся те же данные.

## Как выложить (бесплатно, постоянная ссылка)

Приложение полностью статическое — подойдёт любой статический хостинг.

### Вариант A — Netlify (проще всего, без консоли)
1. Зайти на app.netlify.com → «Add new site» → «Deploy manually».
2. Перетащить **папку `календарь-смен-2х2`** целиком в окно загрузки.
3. Готово — Netlify выдаст ссылку вида `https://имя.netlify.app`.

### Вариант B — GitHub Pages
1. Создать репозиторий, загрузить содержимое папки в корень.
2. Settings → Pages → Source: ветка `main`, папка `/root` → Save.
3. Через минуту сайт доступен по `https://логин.github.io/имя-репозитория/`.

### Вариант C — Vercel
1. vercel.com → «Add New Project» → импорт репозитория (или Vercel CLI `vercel`).
2. Framework preset: «Other». Deploy.

> Важно: открывать нужно по адресу `https://…` (или `http://localhost`), а не через
> `file://` — service worker и установка «как приложение» работают только по http(s).

## Установить «как приложение» на телефон

- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран Домой».
- **Android (Chrome):** открыть ссылку → меню ⋮ → «Установить приложение».

Появится иконка на рабочем столе, запуск в полноэкранном режиме, работа офлайн.

## Как считается график

Для каждого человека: `цикл = рабочих + выходных` (для 2×2 — 4 дня).
День считается рабочим, если `(дата − дата_старта) mod цикл < рабочих_дней`.
Поэтому достаточно один раз указать любой рабочий день — весь календарь
строится сам на любые месяцы вперёд и назад.
